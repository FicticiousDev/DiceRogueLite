# DiceBuilderRogueLite

*Working title.* A 3D, turn-based rogue-lite played on hexagonal tiles. A play on the deck-builder genre where the deck is a pool of dice: every turn the whole pool is rolled and the results are spent to move, attack and defend.

- Engine: Godot 4.7.2 (Forward Plus, Jolt Physics)
- Design: `Dice Game.canvas` (Obsidian vault / Claude project)
- Development plan: `Dice_Roguelike_Development_Plan.md` (Obsidian vault / Claude project)

The previous prototype is kept locally in `_archived/` (git-ignored, Godot-ignored).
